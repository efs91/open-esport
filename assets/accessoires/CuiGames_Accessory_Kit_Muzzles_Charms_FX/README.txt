CuiGames Accessory Kit – Muzzles, charms & Unity FX
by CuiGames · @GodTrigger0 · https://cuigames.itch.io/accessory-kit

This download: 8 looks (5 muzzles + 3 charms) + optional Unity effects

Muzzles/  MC01 compensator, MB01 brake, FH01 flash hider, SC01 short suppressor, SL01 slim long suppressor (textures/ included)
Charms/   Micro Terminal, Honey Cub, Stardrop (smoke teal glass) + Unity material helper
Extras/   Unity_FX01_EXPERIMENTAL – scope picture-in-picture, flashlight, pointer beam. NOT verified in Unity Editor.

FILE TYPES
- .glb   glTF 2.0 binary, PBR materials, textures embedded.
- .fbx   for Unity/Unreal; re-tune glass and emission in your engine (textures: re-assign from the .blend if needed).
- .blend editable Blender source (Blender 5.0+), images packed.

ATTACHMENT
- Each model has one root empty = attachment point. Parent it to your weapon socket.
- Exported Y-up. Check orientation and scale once after import.
- A5_Rail fits the A5 Carbine top rail, X50_Rail fits the X50 heavy rifle front rail,
  Legacy_K1_Rail = generic picatinny-style seat from an older test host (adjust position yourself).

NOTES
- Scopes use the new M02 PBR finish (updated 2026-10). Static props, no rigs/animations, no LODs.
- Glass looks opaque in viewers without glTF transmission support.
- Not verified inside the Unity Editor. Magnifications/effects are game visuals only.
- Other packs on the page: A5_Rail, X50_Rail, Legacy_K1_Rail, Muzzles_Charms_FX. Download only what you need;
  all packs can be unzipped into the same folder.
